# How to Run This Web Application
This web application was mainly developed in HTML, CSS, and JavaScript to work with Google Chrome (chrome apps). If you're running a web browser such as Safari or Firefox and you find some kind of issue or sub (whether that be visual or a functional issue), please create an issue on the official [ModernClock GitHub](https://github.com/futuretempdraws/Modern-Clock).

To write/open any issues (you might need a GitHub account), [click here](https://github.com/futuretempdraws/Modern-Clock/issues).

## Opening and Running
When you download the ZIP file that contains all of the source files, make sure you locate the file labeled "ModernClock.html" and double click it.

If Chrome (or any broswer that runs on Chromium) is your default browser, it should run in that browser.
